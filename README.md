# 01 - Ideation Phase

## Project Name

Employee Laptop Request Application by ServiceNow

## Problem Statement

Employees often face difficulties when requesting laptops or replacement devices through emails, spreadsheets, or manual processes. IT teams also face challenges in tracking laptop requests, obtaining manager approvals, checking inventory availability, assigning devices, monitoring request status, and maintaining a complete history of laptop allocations.

The absence of a centralized and automated system can result in delayed approvals, inefficient inventory management, lack of request visibility, duplicate communication, and difficulty tracking the complete laptop request lifecycle.

## Proposed Idea

Develop an Employee Laptop Request Application using the ServiceNow platform to provide a centralized system for submitting laptop requests, obtaining manager approvals, checking laptop inventory, assigning devices, tracking request status, automating notifications, and maintaining a complete audit trail.

The application will connect employees, managers, and IT support teams through a structured workflow and role-based access system.

## Target Users

* IT Support Staff
* IT Managers
* System Administrators
